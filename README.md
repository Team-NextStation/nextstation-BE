# 환승여행 BE

## 서비스 소개

반복되는 일상 속에서 스쳐 지나가던 역을 여행지로 바라보면, 도시가 조금 다르게 보입니다.

환승여행은 익숙한 지하철역을 새로운 여행 출발점으로 바꿔, 일상 속에서 가볍게 새로운 장소와 코스를 발견할 수 있도록 돕는 서비스입니다.
지하철역을 기준으로 주변 장소와 코스를 탐색하고, 사용자의 취향에 맞는 여행 경험을 제안합니다.

직접 코스를 만들고, 추천 코스를 둘러보고, 다녀온 여행을 기록하며 나만의 도시 여행을 쌓아갈 수 있습니다.

## 로컬 개발환경 실행

### 사전 요구사항
* `Docker`, `Docker Compose`

### 실행 및 종료

프로젝트 루트 디렉토리에서 아래 명령어를 실행합니다.

```bash
# 로컬 컨테이너 환경 실행
docker compose -f docker-compose-local.yml up -d

# 로컬 컨테이너 환경 종료
docker compose -f docker-compose-local.yml down
```
